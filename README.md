# User Management API (Flask + SQLite)

Bu projemde, Python Flask kullanılarak geliştirilmiş basit bir kullanıcı yönetim API’si tasarladım.  

Kullanıcı ekleme, listeleme, güncelleme ve silme işlemlerini SQLite veritabanı üzerinden gerçekleştirdim.



## Özellikler :

- POST ile kullanıcı ekleme 
- GET ile kullanıcı listeleme 
- PUT ile kullanıcı güncelleme 
- DELETE ile kullanıcı silme 
- SQLite veritabanı kullanımı 



##  Kullanılan Teknolojiler :

- Python
- Flask
- SQLite
- Postman uygulaması
